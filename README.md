# Kassza – ingyenes, offline költségkövető

Borítékos költségvetés, költségkövetés és elemzés. Telefonon telepíthető (PWA), internet nélkül is működik. Az adatok csak az eszközön vannak.

**Megnyitás:** https://vargabali182-cmyk.github.io/kassza/

Telefonon: nyisd meg egyszer, majd „Főképernyőhöz adás” (iPhone, Safari) vagy „Alkalmazás telepítése” (Android, Chrome).

## Funkciók
- Borítékos (zero-based) költségvetés, maradék átvitele, túlköltés kezelése, automatikus kiosztás
- Kiadás / bevétel / átvezetés, megosztott tételek, címkék, keresés, naptár nézet
- Több számla és pénznem, egyenleg-egyeztetés, nettó vagyon
- Ismétlődő tételek és előfizetések, automatikus rögzítéssel
- Megtakarítási célok, kölcsönök és tartozások
- Elemzés: hová megy a pénz, kiugró kategóriák, apró gyakori költések, előfizetés-felismerés, banki díjak, 50/30/20, előrejelzés, lehetséges megtakarítás
- Revolut kivonat import (Androidon közvetlen megosztással), banki CSV import, automatikus kategorizálás
- Csomag- és kedvezménykereső a Claude-dal (Claude előfizetéssel vagy saját API kulccsal)
- CSV export, JSON mentés és visszaállítás, PIN zár, sötét mód

## Adatvédelem
Minden adat a böngésző helyi tárolójában van. Kifelé csak akkor megy adat, ha a felhasználó maga indítja a Claude-os átnézést; ilyenkor is csak összesítés (kategóriánkénti és boltonkénti havi összegek), egyedi tételek, számlaszám és egyenleg nélkül.
